1. Unzip this file. Open the unzipped folder: you must see settings.gradle.kts, build.gradle.kts, app and .github right there.
2. Upload THE CONTENTS of that folder (not the folder itself) to the root of your GitHub repository.
   Hidden folder .github may be skipped by your browser: if so, create .github/workflows/build.yml on GitHub using "Add file > Create new file" and paste the text from build.yml.
3. Actions tab > Build APK > download CallForwarder-apk > unzip > install app-debug.apk.
